# starter

A beginner Python project: a number guessing game.

## How to run

You need [Python 3](https://www.python.org/downloads/) installed.

```bash
python main.py
```

## How it works

The computer picks a random number from 1 to 100. You guess, and it tells you
whether to go higher or lower until you get it right.

## Ideas to extend it

- Add difficulty levels (1-10, 1-100, 1-1000)
- Limit the number of guesses
- Keep track of your best score
